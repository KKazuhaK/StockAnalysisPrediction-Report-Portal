# v0.4.50 — execution modes and preset-window waiting in the queue

## Upgrade notes

From v0.4.49, pull and restart. No schema change, migration, or new setting.
Existing jobs use their stored schedule and preset snapshot. Historical cancellation states are
preserved; the release does not restart cancelled jobs or reconstruct scheduling rules that were
previously cleared. Rolling back to v0.4.49 restores the previous queue presentation.

## Fixed

- The queue list, header drawer, and job details show immediate, scheduled, or preset execution
  together with normal, urgent, or idle priority. Mode labels remain visible on narrow screens
  and after completion while the stored schedule is retained.
- Jobs currently blocked by an inverted preset show that they are waiting for the excluded
  window to end, rather than claiming to be next in line. They count toward scheduled jobs in
  the queue summary and do not receive an admission position.
- Shared job queries now read the existing preset snapshot, so list and detail responses can
  distinguish a preset from an ordinary scheduled start.
- Fully cancelled jobs have a neutral gray progress bar without a success checkmark. Queued
  rows are no longer counted as cancelled just because they have not produced a result.
- Manually rescheduling a job or choosing Run now replaces its preset eligibility rule, so a
  previous excluded window cannot silently prevent the requested schedule from taking effect.

## Validation

Browser checks against a local Go binary serving its embedded production SPA, using an isolated
SQLite database: immediate, scheduled, and preset priority combinations; inverted-window waiting;
job details; header drawer; cancelled progress; Chinese labels; desktop and phone layouts.

Regression coverage includes stored preset snapshots through the queue API and summary, manual
schedule overrides, and execution labels. The preset-window sweep fixture now formats UTC
instants through the production local-time formatter so it also passes in non-UTC environments.
