# v0.4.70 — legacy input-help compatibility

From v0.4.69, pull and restart. No database schema change or migration is required.

## Run analysis

- Existing Dify targets created before structured input descriptions now recover their compact
  labels and information controls without requiring every field to be edited again.
- The compatibility fallback is workflow-agnostic: when an input has no explicit description, a
  trailing parenthetical note is presented behind the information control. It never checks field
  keys or workflow names.
- Explicit target display names and descriptions remain authoritative, and optional state still
  comes only from the declared `required` flag.
- A note that only repeats the optional state is removed from the title without creating an empty
  information control.

## Validation

Targeted input-metadata and run-modal tests, frontend type checking, the complete frontend suite,
and the production frontend build pass.
