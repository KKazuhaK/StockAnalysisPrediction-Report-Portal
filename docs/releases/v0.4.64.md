From v0.4.63, pull and restart. No schema change, migration, or new setting.
Report tabs now show the exact generator workflow version when the producer supplies it, for example
`投资决策建议 · V3.15.5`. The existing report version remains independent and still identifies the
written form (`default`, `人工`, `内部版`, `外部版`); when both axes apply, the tab composes them, for
example `投资决策建议 · V3.15.5 · 人工`.

- A structured version suffix in the ingest source is authoritative. Older reports whose source did
  not carry one fall back to the historical title suffix, so existing `V3.15` reports remain
  identifiable.
- Configured report-type labels keep the generator suffix, and both stock and run pages receive the
  same label from the API. The full report title and export filename are unchanged.
- The end-to-end release check now reflects the seeded default and hand-written report versions.

The Go suite, vet, build, frontend typecheck, all frontend tests, production frontend build, and the
throwaway-database HTTP end-to-end check pass.
