# v0.4.69 — visible run-input help controls

From v0.4.68, pull and restart. No database schema change or migration is required.

## Run analysis

- Input help now uses a fixed-size information control instead of the smaller question-mark control.
- The control keeps a 28-by-28-pixel hit area with an 18-pixel icon and reserved label space, so long
  field names and the two-column desktop layout cannot compress it.
- Help visibility remains driven by the input's explicit `description`; no workflow keys or labels are
  hard-coded into the run form.

## Validation

Frontend type checking, all 746 frontend tests, and the production frontend build pass.
