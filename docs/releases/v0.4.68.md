# v0.4.68 — structured input help

From v0.4.67, pull and restart. No database schema change or migration is required.

## Workflow inputs

- Run and batch forms no longer parse parentheses or keywords inside an input label. Labels remain
  intact, optional state comes only from the declared `required` flag, and help buttons appear only
  when the input carries an explicit `description`.
- Dify targets can define a portal-specific display name and description for each input in the
  target editor. The original Dify label remains stored unchanged.
- Re-probing a target or applying a bulk Dify refresh preserves portal display names and
  descriptions by input variable, while continuing to refresh structural fields from Dify.
- Custom executor manifests may declare the same optional `description` property.

## Validation

Frontend type checking, the complete frontend test suite, the production frontend build, repository
build/vet/tests, and browser checks for the target metadata editor and run-form help rendering pass.
