# =====================================================================
# font-coverage-corpus.txt
# =====================================================================
#
# WHAT THIS IS
#   The single source of truth for which characters an exported PDF must be
#   able to draw.
#
#   Its one consumer is scripts/probe-font-coverage.sh, the build-time gate in
#   the runtime-base stage of Dockerfile.release — built on every push and pull
#   request by the font-image job in .github/workflows/test.yml (amd64), and
#   again by the release image build (both arches). The gate asks fontconfig
#   whether some installed font CLAIMS each codepoint, and fails the build when
#   a `require` codepoint is claimed by none. Add a codepoint here and the gate
#   picks it up; do not keep a second list anywhere else.
#
#   WHAT THIS FILE DOES NOT BUY YOU. Claiming a codepoint is not the same as
#   painting one, and nothing in the repo checks the latter across this list.
#   The gate narrows the gap by counting only fonts fontconfig reports as
#   outline and non-colour, which is what excludes the emoji builds whose base
#   glyphs are empty - but a font that claims a codepoint and draws a blank is
#   still, in principle, invisible to it. Tiers were established by rendering
#   every line once by hand (see HOW THE TIERS BELOW WERE ESTABLISHED); that
#   was a one-off, not a standing check.
#
# WHY IT EXISTS
#   Reports are written by an LLM, in Chinese, and rendered headlessly by
#   wkhtmltopdf inside a debian:bookworm-slim image that has no fonts of its
#   own. Every glyph the model reaches for has to be in a font we installed
#   on purpose. A missing glyph does not error - wkhtmltopdf silently draws
#   nothing - so the failure only ever surfaces as a hole in a customer PDF.
#
# FORMAT
#   Three TAB-separated columns, one codepoint per line:
#
#     U+2705<TAB>ballot<TAB>require
#     U+00A0<TAB>space<TAB>nonprinting
#     U+20BF<TAB>currency<TAB>advisory
#
#   Column 1  codepoint, always written as U+XXXX text and never as a literal
#             character, so this file is pure ASCII and survives any locale,
#             editor or terminal it passes through.
#   Column 2  group slug: lowercase, no spaces.
#   Column 3  exactly one of require | advisory | nonprinting.
#
#   Blank lines are ignored. A line whose first non-blank character is '#' is
#   a comment. Comments are whole-line only - never append one to a data
#   line, because column 3 runs to end of line.
#
# TIERS
#   require      No installed font covers it  ->  FAIL THE BUILD.
#   advisory     Known to be uncovered and accepted. Warn, never fail. Every
#                advisory line carries a comment above it saying why.
#   nonprinting  Must be covered, but is expected to draw ZERO ink: spaces,
#                zero-width controls, joiners, variation selectors. The probe
#                asserts ink == 0 for these, which is how a space that has
#                degraded into a tofu box gets caught.
#
#   The tier is a property of the codepoint, not of its group. U+3000
#   IDEOGRAPHIC SPACE sits in `cjkpunct` and is nonprinting; U+200D and
#   U+FE0F sit in `emoji` and are nonprinting.
#
# FONT SET THIS WAS VERIFIED AGAINST
#   Noto Sans CJK SC  Regular  (OTF/CFF, upstream tag Sans2.004)
#   Noto Emoji        MONOCHROME variable (outline). Noto COLOR Emoji is CBDT
#                     raster and renders blank through wkhtmltopdf - rejected.
#   DejaVu Sans / DejaVu Serif  (fonts-dejavu-core)
#
#   Noto Sans Symbols 2 was evaluated and is NOT required: with it removed,
#   all 594 `require` codepoints below still render with ink. It contributes
#   unique coverage only for U+1F5F4..U+1F5F9 (the astral BALLOT SCRIPT X /
#   BOLD CHECK family), which are deliberately not in this corpus.
#
# HOW THE TIERS BELOW WERE ESTABLISHED
#   Coverage was read from fc-query charsets for the four fonts above, then
#   every line was rendered one-codepoint-per-page through wkhtmltopdf under
#   a fontconfig that rejected every other font on the machine, rasterised at
#   120 dpi with pdftoppm and counted for dark pixels. Result: 594/594
#   `require` drew ink, 23/23 `nonprinting` drew zero ink, and all 6
#   `advisory` drew zero ink (an uncovered codepoint renders blank, not tofu
#   - which is exactly why the gate cannot be skipped).
#
# MAINTENANCE
#   Adding a codepoint: put it in the group it belongs to, default it to
#   `require`, and re-run the probe. If it fails, either install a font that
#   covers it or demote it to `advisory` WITH a comment explaining why.
#   Never demote silently.
#
# =====================================================================
